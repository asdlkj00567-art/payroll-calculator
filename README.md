# 내 월급 계산기 (무료 오프라인 웹앱)

## 구성
- `index.html`: 앱 화면과 계산 기능
- `manifest.webmanifest`: 홈 화면 설치 설정
- `sw.js`: 오프라인 캐시
- `icon.svg`: 앱 아이콘

## 무료로 게시하기 (GitHub Pages 예시)
1. GitHub 계정에서 새 저장소(repository)를 만듭니다. 예: `my-payroll`
2. 이 ZIP의 파일 4개를 저장소 최상위에 업로드합니다.
3. 저장소의 Settings → Pages → Build and deployment에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 Save 합니다.
4. 게시가 완료되면 표시되는 `https://계정이름.github.io/my-payroll/` 주소를 갤럭시 Chrome에서 엽니다.
5. 한 번 온라인으로 접속한 뒤 메뉴(⋮) → `홈 화면에 추가` 또는 `앱 설치`를 선택합니다.
6. 앱을 한 번 더 열어 캐시가 준비되도록 한 다음, 비행기 모드에서 실행을 시험합니다.

## 사용법
- `급여 설정`에서 월 기본급, 월 환산 기준 시간, 기준 시급 및 수당 가산율을 설정합니다.
- `근무 기록 추가`에서 날짜, 종류, 시간, 가산율을 입력하고 저장합니다.
- `월급 요약`에서 월을 선택해 예상 세전 급여를 확인합니다.
- `백업·관리`에서 JSON 백업 또는 CSV 내보내기를 정기적으로 수행합니다.

## 캘린더 및 급여 기간\n- 홈의 달력에서 날짜를 눌러 선택하고 `선택한 날짜에 근무 추가`로 입력 화면으로 이동합니다.\n- 파랑은 잔업, 주황은 특근, 보라는 야간근무입니다.\n- `급여 설정`의 급여 기간 시작일을 선택할 수 있습니다. 예를 들어 21일을 선택하고 2026년 10월을 조회하면 2026-09-21부터 2026-10-20까지의 기록을 집계합니다. 1일을 선택하면 1일부터 말일까지 집계합니다.\n\n## 계산 방식
추가 수당 = 기준 시급 × 근무시간 × 가산율(%)/100
예상 세전 급여 = 월 기본급 + 잔업 수당 + 특근 수당 + 야간 수당

여기서 가산율은 기본 시급에 더해지는 **추가 가산분**만 의미합니다. 예를 들어 50%를 입력하면 시급의 50%를 추가 수당으로 계산합니다. 근무 유형별 가산율, 중복 가산, 휴일근로 계산 및 법정 수당 적용은 회사의 급여 규정과 실제 근로 형태에 따라 다를 수 있으므로 급여명세서와 대조해 설정하세요. 이 앱은 세금·4대 보험·기타 공제를 계산하지 않습니다.

## 개인정보와 데이터
근무 기록과 설정은 이 브라우저의 `localStorage`에만 저장됩니다. 별도 서버로 전송하지 않습니다. 브라우저 데이터 삭제, 사이트 데이터 정리, 앱/브라우저 제거 또는 휴대폰 초기화 시 데이터가 없어질 수 있으므로 백업 파일을 안전한 곳에 보관하세요. 시크릿 모드에서는 사용하지 마세요.

## 업데이트
앱 파일을 바꾸면 서비스 워커 캐시 이름(`payroll-pwa-v1`)을 `payroll-pwa-v2` 등으로 변경한 뒤 다시 게시하면 업데이트를 더 확실히 반영할 수 있습니다.
